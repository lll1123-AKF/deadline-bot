这个演示还原了项目的哪些能力

通知解析

从自然语言中抽取标题、截止日、来源、类别与优先级。规则优先，覆盖 7 类中文日期表达。

内容排序

综合优先级、类别提前量、紧迫度、进行中状态计算「该先做分数」，每条都给出理由。

进度跟踪

完成率、进度条、状态分布、今日聚焦，随时开始 / 改进度 / 标记完成。

随时可改

改优先级、改截止日（支持自然语言）、加备注、删除，排序实时重算。

真实项目是 基于 nanobot 工作区 Skill 机制的 Python 二次开发：nanobot 负责对话、记忆与定时触发，本项目提供领域能力。本页用 JavaScript 复刻了同一套逻辑，便于在线体验。
