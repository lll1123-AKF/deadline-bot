这个演示还原了项目的哪些能力

    

      
通知解析
从自然语言中抽取标题、截止日、来源、类别与优先级。规则优先，覆盖 7 类中文日期表达。

      
内容排序
综合优先级、类别提前量、紧迫度、进行中状态计算「该先做分数」，每条都给出理由。

      
进度跟踪
完成率、进度条、状态分布、今日聚焦，随时开始 / 改进度 / 标记完成。

      
随时可改
改优先级、改截止日（支持自然语言）、加备注、删除，排序实时重算。

    

    
Python 端是一个独立实现的精简 Agent Runtime：消息总线、工具注册表与参数校验、上下文构建、多轮 tool-calling 循环、会话记忆压缩、定时调度与三种渠道适配器。本页用 JavaScript 复刻了领域逻辑，方便没有后端时在线体验；启动 python server.py 后可直接观察真实内核的工具调用链。nanobot 只是可选的接入渠道之一，不是项目主体。
